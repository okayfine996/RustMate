# RustMate Updates

This repository hosts the update feeds for RustMate.

## Appcast Files

- [appcast-stable.xml](appcast-stable.xml) - Stable channel updates
- [appcast-beta.xml](appcast-beta.xml) - Beta channel updates (includes stable releases)

## URLs

These appcast files are hosted on GitHub Pages and can be accessed at:

- Stable: https://okayfine996.github.io/RustMate/appcast-stable.xml
- Beta: https://okayfine996.github.io/RustMate/appcast-beta.xml

## Automatic Updates

RustMate uses Sparkle 2 for automatic updates. These appcast files are automatically updated when new releases are published via GitHub Actions.
